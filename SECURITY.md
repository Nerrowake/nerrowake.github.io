# Security Policy

This repository is a static legal site. Security issues should still be reported
privately when they involve sensitive information.

## Reporting

Use GitHub private vulnerability reporting when available, or contact the
maintainer privately.

## Relevant Issues

- accidental exposure of private contact details
- unsafe external links
- compromised assets
- unexpected scripts or tracking code
- GitHub Pages deployment concerns

## Public Issues

Do not open public issues containing private data or sensitive legal concerns.

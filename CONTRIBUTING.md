# Contributing to Nerrowake Legal

This repository contains public legal pages for Nerrowake and Wakebot.

## Guidelines

- Do not change legal policy text casually.
- Keep changes small and reviewable.
- Preserve the static HTML/CSS structure unless there is a clear reason to add a
  build step.
- Update `CHANGELOG.md` for legal policy changes.
- Verify pages render locally before pushing.

## Local Check

Open the HTML files directly in a browser or run:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
